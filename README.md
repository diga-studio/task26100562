# TalentPulse 候选人匹配库

进程内候选人匹配库（Go），由上层直接调用，无外部服务依赖。

## 功能

- `NewMatcher()` 创建匹配库；`AddBatch` 批量录入；`Replace` 按 ID 整份替换档案。
- `Query` 在指定人才池内按过滤条件筛选并排名，返回前 K 名（总分降序、ID 升序）。
- 过滤条件支持任意嵌套 `AND`/`OR`/`NOT`，叶子为持有技能或经验月数闭区间；只决定入选，不参与计分。
- 总分 = 命中技能权重之和 + `min(经验,目标)/目标*经验权重`，排序使用整数分子精确比较，不受浮点截断影响。
- 替换档案后立即生效，旧技能、旧经验、旧人才池不再被命中。
